# WORLDVOICECM Store — Fixed GitHub Pages Build

Static HTML/CSS/JS store. No npm or build step.

## Upload
Upload `index.html`, `styles.css`, `script.js` and the `assets` folder to the repository root.

The ADD TO BAG buttons are real HTML buttons. The bag opens as a side drawer and the cart is stored in localStorage.
Product names/prices are demo content until replaced with the final catalog.
